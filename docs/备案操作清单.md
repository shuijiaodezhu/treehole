# 备案操作清单（买完服务器之后，照着点）

> 配套文档：[国内合规上线.md](./国内合规上线.md)（路线图、材料清单、上线步骤）
> 这份只讲**一件事**：从"刚买完服务器"到"拿到备案号"，在控制台里点哪些、每个字段填什么。

---

## 0. 前置判断（不满足就别往下走）

- [ ] 主体：**企业/个体工商户**（推荐 ✓）还是个人
      → 交互式内容（发帖/评论/私信）**个人备案走不通**，见路线图第 0 节
- [ ] 域名已买 ✓ 且**实名认证已通过**（没过的话备案系统第一步就卡住 ✗）
- [ ] 服务器已买 ✓ 且**时长 ≥ 3 个月**（建议直接 1 年 ✓ 审核期间不能过期 ✗）
- [ ] 一个手机号 + 常用邮箱（要能收验证码 ✓ 且**必须是主体本人的实名手机号** ✓）

---

## 1. 买服务器时怎么选（腾讯云 / 阿里云都一样）

| 项 | 选什么 | 为什么 |
|---|---|---|
| 产品 | **轻量应用服务器** | 够用、便宜 ✓ |
| 地域 | **大陆**（上海 / 广州 / 北京，选离你近的）| 只有境内服务器才能备案 ✓ |
| 规格 | 2核2G 起 | 备案本身不吃性能 ✓；以后跑 Nginx/Node 也够 ✓ |
| 系统盘 | 40-50GB SSD | 20G 容易满 ✗ |
| 时长 | **1 年**（别选 1 个月 ✗）| 审核期间过期 = 备案失败，白等 ✗ |
| 镜像 | **Ubuntu 22.04 LTS** | 后面给的命令都是这个系统 ✓ |
| 带宽 | 尽量选**大一点**那档（3M/6M…）| 这是以后体验的关键 ✓ 差价不大 ✓ |

## 2. 领「备案服务号 / 备案授权码」

两家叫法不同，**东西是一回事**：

- **阿里云** → 叫「**备案服务号**」
- **腾讯云** → 叫「**备案授权码**」

领取路径（大致）：

```
云厂商控制台 → 搜「备案」→ 进入备案控制台
→ 「开始备案」/「申请备案服务号（授权码）」
→ 选择你要备案的那台服务器 → 系统校验（会自动检查实名、时长、地域）
→ 生成一串编号（形如 1234567890 或授权码字符串）← 记下来，备案表单里要填
```

⚠️ 校验不通过的常见原因：
- 域名还没实名 / 实名还在审核中 ✗
- 服务器时长 < 3 个月 ✗
- 服务器地域不是大陆 ✗
- 该服务器已经用完了赠送的备案数量 ✗（一台轻量通常送 1-5 个）

## 3. 填备案表单（逐项）

### 3.1 主体信息

| 字段 | 怎么填 |
|---|---|
| 主办单位性质 | 个体工商户 / 企业（推荐 ✓）或 个人 |
| 主办单位名称 | **营业执照上的全称**，一个字都不能错 ⚠️（错字是常见驳回原因 ✓）|
| 证件号码 | 统一社会信用代码（企业）/ 身份证号（个人）⚠️ 逐位核对 |
| 证件住所 | 营业执照上的地址，一字不差 ⚠️ |
| 主体负责人 | 法人本人（若不是法人，要上传授权书 ✓）|
| 手机号 | **本人实名**的手机号 ✓（不是本人的会被驳 ✗）|
| 邮箱 | 常用邮箱 ✓（审核通知发这里 ✓）|
| 应急联系电话 | 部分地区必填 ✓ 可以填家人的（要能打通 ✓）|

### 3.2 网站信息

| 字段 | 怎么填 |
|---|---|
| 网站名称 | 见下方「名称雷区」✓ 建议：**你的来信**（个人）/ **XX 网络工作室**（企业）|
| 网站服务内容 | 企业可选「其他」→ 手填「**个人作品展示、记录分享**」× 不要写论坛/社区 ✗ |
| 网站域名 | 填你备案的域名（`xxx.cn` ✓）不带 `www` 也能过 ✓ |
| 网站负责人 | 通常与主体负责人一致 ✓ |
| 服务器 IP | 系统会自动带出（你选了备案服务号 ✓）|
| 网站语言 | 简体中文 ✓ |

**名称雷区** ⚠️（名字不对，多数会直接驳）
```
✗ 论坛 / 社区 / 贴吧 / 博客（个人备案）/ 新闻 / 直播 / 教育 / 医疗 / 支付 / 商城
✗ 含「中国 / 中华 / 国家 / 政府」等字样
✗ 纯英文名（部分地区要求中文）
✗ 与知名品牌/网站近似
✓ 你的来信 · 来信手记 · XX 个人主页 · XX 网络工作室
```

### 3.3 真实性核验

| 方式 | 说明 |
|---|---|
| 视频核验（现在多数地区用这个）| 在备案 App/小程序里按提示读一段话 + 人脸 ✓ 几分钟 ✓ |
| 幕布照片（少数地区仍要）| 厂商免费寄幕布 ✓ 站前面拍半身照 ✓ 有的要手持身份证 ✓ |
| 核验单 | 系统生成 → 打印 → **手写签名 / 盖章** → 拍照上传 ✓ |

## 4. 提交后的时间线

```
① 厂商初审        1-2 个工作日  ← 会打电话核实！⚠️ 陌生来电务必接
② 提交管局        当天
③ 管局审核        1-20 个工作日（一般 7-10 天）
④ 通过            收到短信/邮件，拿到备案号（形如 苏ICP备2025xxxxxx号）
⑤ 公安联网备案    通过后 **30 日内**，在「全国互联网安全管理服务平台」提交 ⚠️
```

**审核期间三条纪律**：
```
✓ 电话保持畅通（这一条最常见的驳回原因就是"未接核验电话"）
✗ 不要修改域名解析（尤其是别往境外指 ✗）
✗ 不要让服务器过期、不要改主体信息
```

## 5. 常见驳回原因与预防（照着自查）

| 驳回原因 | 预防 |
|---|---|
| 网站名称不合规 | 用上面「名称雷区」里的安全写法 ✓ |
| 手机号非本人实名 | 换成本人实名的号码 ✓ |
| 证件照片模糊/反光/缺角 | 白底、平铺、四角齐全、别开闪光灯 ✓ |
| 主体信息与营业执照不一致 | 逐字核对（地址、名称）✓ |
| 核验电话未接 | 审核期别静音陌生来电 ✓ |
| 域名未实名 / 实名未通过 | 先做域名实名，等通过再提交 ✓ |
| 服务器时长不足 3 个月 | 买 1 年 ✓ |
| 同一主体已有其他备案冲突 | 先在备案系统查一下历史备案 ✓ |
| 网站内容与备案信息不符 | 备案通过前别对外开站 ✓ 站点内容与"服务内容"描述一致 ✓ |

## 6. 拿到备案号之后（当天做三件事）

```
① 域名解析：把 `xxx.cn` 的 A 记录指向那台大陆服务器的公网 IP ✓
② 页脚挂备案号（法规要求必须展示）✓
     文案：苏ICP备2025xxxxxx号
     链接：https://beian.miit.gov.cn/
     ⚠️ 代码里要改的位置：components/home-current.tsx 与 home-classic.tsx 的页脚
     （做这一步时叫我，我改 ✓）
③ 公安联网备案（30 日内）✓
     全国互联网安全管理服务平台 → 注册 → 网站备案 → 填域名/IP/备案号 → 提交
     通过后再拿一个「公安备案号」，同样挂在页脚 ✓
```
