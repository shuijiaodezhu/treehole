## ② 你们报的、已经修好的 ✓

| # | 现象 | 真正的原因 | 修法 |
|---|---|---|---|
| 1 | **首页每次刷新字都会跳** | 标题"写一遍"动画由两个事件触发，**每进一次首页都重放** | 用 `sessionStorage` 记住"本次会话已播过" → 之后直接显示；登录过场后仍写一遍 |
| 2 | 从**首页铃铛**进通知页、按返回**跳到个人主页** | 通知页的「返回」是**写死** `href="/me"` | 改成回到**来时的页面**（无历史则回首页）|
| 3 | **看过的私信还有红点**（小屋那个数字，永远消不掉）| 已读标记用**手机本地时钟** `new Date()`，而未读判定比的是**服务器时间** → 手机时钟慢一点就永远算未读 | 已读位置改用**服务器那条消息的时间**（两边同源）；老标记进一次聊天就自愈 |
| 4 | 通知看过了，**别处角标还挂着红点** | 通知页读完**没有通知别处刷新**；而且角标有 60 秒不重算的门槛 | 读完（全部/单条/清空）派发一次「角标立即刷新」事件 |
| 5 | **"从小屋出来就要重新登录"**（朋友报的）| 全项目 **24 处**用 `getUser()` 判断登录，而它**每次都要联网** → 跨境抖一下/超时就判定"没登录"→ 踢去登录页 | 在 `app/lib/supabase.ts` 加一层兜底：**先读本地会话**（瞬时），本地没有才联网确认 → 24 处一起变稳，还顺便省掉一次跨境请求 |
| 6 | **选中文字变成一片黑** | 没声明 `::selection` → 系统深色模式下浏览器默认选中色是黑的 | 用主题强调色写 `::selection`（字仍是墨色）|
| 7 | **App 里天气显示香港** / 定位不可用 | 安卓壳**没申请定位权限**，也没接 WebView 的定位回调 | 壳子加权限 + 接 `onGeolocationPermissionsShowPrompt`（像一般 App 那样弹授权，拒绝也不崩）→ 需要重装最新 apk |
| 8 | **点赞/切页要等半天** | 点赞先写库、**还顺手把整页重拉一遍**（4 次查询 ≈ 600ms）；院子一页本身 4 次串行查询 ≈ 900ms | 点赞改**乐观更新**（先改界面、失败回滚）；院子改**一次拿回整页**（`world_feed` 函数），并带兜底 |
| 9 | **登录/打开慢** | 登录幕布 2.2 秒；字体 CSS **106KB 且阻塞首屏**；每页都多一次跨境 `getUser()`；页面代码要现下载 | 幕布 → 1.0 秒；字体改**懒加载**不阻塞；`getUser` 本地优先；`router.prefetch` 预热 5 个页面；预连接数据库域名 |
| 10 | **iQOO 装不上 / 无法识别** | 下载到的是 **zip** 或传输中被改名；vivo 的纯净模式拦截 | 云端构建自动发 **Release**，得到一条**直链**（点开直接下载 apk，不用登录不用解压）|
| 11 | **TWA 装在手机上卡在启动图** | TWA 依赖 Chrome，而国产手机常常没有 Chrome | 改做**自带内核的 WebView 壳**（不依赖 Chrome），用 GitHub Actions 云端构建 |
| 12 | **App 里存不了东西？** | 担心项 | 实测壳子 `domStorageEnabled` / `databaseEnabled` **本来就开着** ✓ 且没有任何清缓存逻辑 → **已经能存** ✓ 不用重装 |

## ④ 由这些错误定下的规矩（我以后必须守）

```
1. 一次只改一件事，一个提交只做一件事 ✓
   （4 条挤一起 → 挂了我分不清是谁 ✗ 这是最贵的一次教训）

2. 凡是"页面要等网络"的地方，**一律加超时兜底** ✓
   （构建检查查不出"网络慢会怎样"✗ 只有真机才会暴露）

3. 猜的东西不许上路 ✓
   字体文件名、锚点位置、列名 —— 一律**先读原文/先实测**再改 ✓

4. 改完必须读回校验 ✓ 校验不过**绝不提交** ✓
   （有一次校验失败还提交了 ✗ 删掉了整个主题块）

5. 提交前跑三件：tsc / eslint（基线 0 条）/ next build ✓ 全绿才提交 ✓

6. 危险改动（合请求、Service Worker、删代码）必须留**回退路径** ✓
   新路 + 老路并存 → 最坏只是"没变快"，不能是"打不开" ✓

7. 批量删代码只删**一个**，删完立刻 tsc ✓
   （一次删两个就删坏过 ✗）

8. 做完从**外部**验，不听自己说 ✓
   （抓线上文件找特征字符串、逐个接口 200、逐路由核对 ✓）
```
